# Kerf AI

AI video and photo editor: a sales page plus a chat editor (`index.html`, open `#app` for the editor).

- Static site, deployed on Vercel from the `main` branch.
- Accounts and saved chats use Supabase (project `kerf-ai`). The publishable key in `index.html` is safe to ship; every table is protected by row-level security.
- Sample videos and posters sit next to `index.html`.
